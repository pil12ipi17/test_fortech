Fortech Stage 3

Task Console

Небольшой интерфейс для проверки реальных backend-сценариев: вход, регистрация, список задач с фильтрами, создание задач, смена статуса и отображение ошибок API.

Единая точка входа

Frontend и backend доступны через gateway на localhost:8080.

Backend-first логика

RBAC, lifecycle, audit и idempotency остаются на backend, UI только вызывает реальные API.

Живые сценарии

После входа можно создать задачу, отфильтровать список и перевести задачу по статусам.

Войти в систему

Используется маршрут POST /api/v1/auth/login.

Создать пользователя

Используется маршрут POST /api/v1/auth/register с автоматическим открытием сессии.
