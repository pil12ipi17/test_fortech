Task Console

Небольшой интерфейс для проверки реальных backend-сценариев: вход, регистрация, фильтрация задач, создание задач, смена статуса и понятное отображение ошибок API.

Один адрес для всего

И UI, и API доступны через gateway на localhost.

Реальные backend-правила

RBAC, lifecycle, audit и idempotency по-прежнему живут на backend, а фронт только вызывает контракты.

Удобнее, чем Swagger

После входа можно посмотреть контекст пользователя, найти нужные ID и быстро прогнать рабочий сценарий.

Войти в систему

Используется маршрут POST /api/v1/auth/login.

Создать пользователя

Используется маршрут POST /api/v1/auth/register с автоматическим открытием сессии.

Быстрый маршрут

  1. Войди или зарегистрируйся.
  2. Открой «Справочник», если нужны ID пользователей и команд.
  3. Создай задачу или управляй командами, потом вернись в список и проверь lifecycle.

Роли

Обновление ролей пользователя

Админский сценарий через PATCH /users/{user_id}/roles.

Новые роли

Создание команды

Админский сценарий через POST /teams.

Добавление участника в команду

Админский сценарий через POST /teams/{team_id}/members.

Ручной запуск генерации отчета через POST /audit/report.

Админский сценарий через DELETE /teams/{team_id}/members/{user_id}.
